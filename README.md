## 🚀 部署到 Vercel（免費公開上線）

本專案已完全優化為**獨立純前端架構**，無須任何複雜伺服器常駐，內建 J.Wood 專屬雲端模擬引擎，部署後 24 小時小人都會在線上生動走動！

### 步驟 1：推送到 GitHub
1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如命名為：`jwood-ai-office`。
2. 在本地專案資料夾 `jwood-ai-office` 內執行：
```bash
git init
git add .
git commit -m "feat: initial commit of J.Wood Studio AI Office"
git branch -M main
git remote add origin https://github.com/你的GitHub帳號/jwood-ai-office.git
git push -u origin main
```

### 步驟 2：一鍵發布到 Vercel
1. 前往 [Vercel 官網 (vercel.com)](https://vercel.com/)，點擊 **Sign Up / Log In**（建議直接以 GitHub 帳號登入）。
2. 登入後點擊右上角 **「Add New...」 ➔ 「Project」**。
3. 在列表裡找到剛才建立的 **`jwood-ai-office`**，點擊 **「Import」**。
4. 設定頁面保持預設（Framework Preset 選 Other，Root Directory 保持 `./`），直接點擊 **「Deploy」**！
5. 約 30 秒後，Vercel 就會發給你一個專屬的公開網址（例如：`https://jwood-ai-office.vercel.app`）！
